# Oracle Consult Ghana Website

A responsive static website built with HTML, CSS and JavaScript using the brand identity:
- Deep blue: `#102B5C`
- Yellow accent: `#F9C928`
- White: `#FFFFFF`
- Tagline: “Your brand, always online. Your customers, always engaged.”
- Social handle: `@oracleconsultghana`

## Files
- `index.html` — website content and structure
- `style.css` — layout, colors, responsive styling
- `script.js` — mobile navigation, current year, and enquiry form behavior

## Preview on your computer
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension and click **Go Live**.

## Publish on Netlify
1. Extract the ZIP.
2. Sign in to Netlify and choose **Add new site** / **Deploy manually** (wording may vary).
3. Drag the extracted website folder (the folder containing `index.html`) into the deploy area.
4. Netlify will provide a preview URL.

## Before publishing
1. In `script.js`, replace `YOUR_EMAIL@example.com` with the real email address where you want enquiries sent.
2. Verify the Instagram, Facebook and TikTok URLs in `index.html`; replace them with your exact profile URLs if needed.
3. The enquiry form currently opens the visitor's email app using `mailto:`. It does not store submissions or send them directly from the website.
4. The Montserrat font loads from Google Fonts; if offline, the site falls back to Arial.

This is a static front-end site. It does not include an admin dashboard, blog CMS, online booking system, or server-side form processing.
